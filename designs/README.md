## 🖨️ Production Notes

### For Print-on-Demand (Printful/Printify):
1. Export SVGs to high-res PNG (300 DPI minimum)
2. Recommended size: 12"x16" for large prints, 8"x10" for chest prints
3. Use transparent backgrounds for designs
4. Test on multiple shirt colors

### Recommended Garments:
- Bella+Canvas 3001 (unisex, 100% cotton)
- Bella+Canvas 3001CVC (heavier cotton-poly blend)
- Colors: Black, vintage white, sage green, charcoal

### Print Methods:
- **DTG (Direct-to-Garment):** Best for complex/multi-color designs (1, 2, 4)
- **Screen Print:** More cost-effective for simple designs (3) or bulk orders
- **Discharge Printing:** Recommended for large back prints on dark shirts (2)
